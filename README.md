# Smart Waste Management System (Smart Waste Sorter)

A Python command line application that automatically sorts waste items, tells users which bin to use keeps a record of past sorting and shows waste statistics.

---

## 📌 Features

- **Waste Sorter:** Enter any waste item. Instantly receive its category the bin color it belongs to (Blue Green, Red, Black) and how to dispose it properly.

- **Knowledge Base Search:** Search for items by keyword or part of the name to quickly see the waste management instructions.

- **Custom Item Registration:** Add waste items on the fly giving them your own category and letting Smart Waste Management System pick the right bin color automatically.

- **Sorting History & Analytics:** Look at logs of every sort and see real‑time statistics about categories and how often each bin is used.

- **Data Persistence:** Smart Waste Management System automatically. Loads the history and your custom items, with a local JSON file called `waste_history.json`.
